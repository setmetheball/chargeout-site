Support for Avanti Tracker

ChargeOut Labs app support

Start and stop tracking

Tap Track a Project, choose or create a project, then start tracking. When finished, tap the red Stop Tracking button beneath the timer.

90-minute reminders

After tracking begins, you can allow optional notifications. Choose Continue to keep tracking and schedule another check-in, or Stop Tracking to end the session.

Live Activity and Dynamic Island

While a project is active, the elapsed time appears in the Dynamic Island on a compatible iPhone and on the Lock Screen. Tap it to return to the timer.

Review and edit history

Open History, then select a project. Project actions let you rename, recolour or delete a project, and individual sessions can be edited or deleted.

Export a report

Open Export, choose a reporting period and projects, then select PDF or CSV. At least one completed matching session is required.

Troubleshooting

The timer was interrupted

Reopen Avanti Tracker. It derives elapsed time from the saved start time and should recover automatically.

A reminder did not appear

Check notification permission. Focus, summaries, Low Power Mode and iOS scheduling may delay delivery; the timer is unaffected.

The Live Activity does not appear

Confirm Live Activities are allowed. Dynamic Island requires a compatible iPhone; other supported iPhones can use the Lock Screen.

An export is empty

Confirm a completed session matches the selected dates and project filter.
